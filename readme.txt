To set up the examination application, the user needs to install the XAMPP v8.0 and click start button beside the apache and mysql and go to the browser and paste this link to the browser tab “localhost/phpmyadmin” and import the database named “cruddb” after the database is set, lets to go the project, first, copy the project and paste to the “xampp/htdocs” folder after the folder/project is set, to browse the project copy this link “localhost/MPrototype/CRUD/index.php/Create” and paste to the browser tab.



Recap:

-Install XAMPP v8.0 and open
-Click start button beside apache and mysql
-Paste localhost/phpmyadmin in the browser tab
-Import database named cruddb
-Copy the project folder and paste to xampp/htdocs
-Open new tab and paste localhost/MPrototype/CRUD/index.php/Create
